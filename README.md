# Base64 Tool — Encode/Decode Swiss Army Knife

Encode and decode Base64, URL parameters, HTML entities, and JWT tokens. Drag-and-drop file support with image preview.

**Live Demo:** [base64tool.surge.sh](https://base64tool.surge.sh/)

## Features

- **5 tools in 1** — Base64, URL, HTML entity, JWT decode, Hash
- **Auto-detect** — Automatically encodes or decodes based on input
- **File support** — Drag and drop any file (text or image)
- **Image preview** — Drops an image, see the Base64 data URL
- **Swap** — Instantly swap input and output
- **Copy/Paste** — One-click clipboard operations

## Tech

- Pure HTML/CSS/JavaScript — zero dependencies
- Works offline, no data uploaded
